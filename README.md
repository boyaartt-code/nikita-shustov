# Никита Шустов — личный сайт

Главный экран: стеклянная шапка, анимированный человечек с мыслями,
колонка «Имущество» и всплывающие окна «бавария», «календарь», «заметки».

## Структура

```
index.html          — главная страница
styles.css          — оформление страницы
app.js              — карточки имущества, окна, календарь, данные «Баварии»
data.js             — ВСЕ ТЕКСТЫ: имущество, особые даты, адрес сервера
server/Code.gs      — общий сервер (Google Apps Script)
img/                — 3D-картинки имущества: audi.webp, house.webp, girl.webp
buddy/
  buddy.js          — анимация и логика эмоций
  buddy.css         — стили (облачко, веки, размеры)
  phrases.js        — все фразы, редактируйте здесь
  assets/           — слои персонажа (WebP)
```

## Как выложить на GitHub Pages

1. Создайте репозиторий на github.com (например, `buddy`).
2. Нажмите **Add file → Upload files** и перетащите всё содержимое этой папки
   (все файлы и папки `buddy`, `img`).
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В блоке *Build and deployment* выберите
   *Source: Deploy from a branch*, ветку `main`, папку `/ (root)`, нажмите **Save**.
5. Через минуту сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/buddy/`.

## Как поменять тексты и картинки

- Тексты — в `data.js`.
- 3D-картинки лежат в `img/`. Чтобы заменить, сохраните новую картинку без фона с тем же именем.
- Сайт на GitHub Pages виден всем: не пишите туда личные данные.

## Окно «Бавария»

Все матчи «Баварии» за сезон: место в таблице Бундеслиги, следующий матч с обратным отсчётом,
ближайшие игры и последние результаты. Турниры помечены значками: БЛ, ЛЧ, Кубок.
Все матчи **автоматически отмечаются в календаре**.

Данные — с бесплатного сервиса OpenLigaDB (без ключа и без сервера): Бундеслига, Лига чемпионов
и Кубок Германии. Обновляются каждые 15 минут.

Внутри предпросмотра Claude внешние данные не загружаются — проверяйте сайт в обычном браузере
или на GitHub Pages.

## Календарь и заметки

- Особые даты (день рождения, годовщина) прописаны в `data.js` → `events` и повторяются каждый год.
- Обычные события: клик по дню → название и время → «Добавить». Крестик удаляет.
- Заметки: «Новая заметка», карандаш — редактировать, крестик — удалить.
- После настройки сервера всё это общее для всех устройств. Изменения — только по PIN-коду,
  остальные посетители видят календарь и заметки, но поменять не могут.

## Настройка общего сервера (один раз, ~10 минут)

1. Создайте новую Google Таблицу, например «Сайт Никиты».
2. В таблице: **Расширения → Apps Script**. Удалите код в редакторе и вставьте весь файл
   `server/Code.gs`. Нажмите «Сохранить».
3. Слева шестерёнка **«Настройки проекта» → «Свойства скрипта» → «Добавить свойство»**:
   `PIN` — код для изменений (например, 4 цифры).
4. Вверху выберите функцию `test` и нажмите **«Выполнить»**. Google попросит разрешения:
   «Проверить разрешения» → ваш аккаунт → «Дополнительные настройки» → «Перейти в проект» → «Разрешить».
   В таблице появятся листы «События» и «Заметки».
5. **«Развернуть» → «Новое развертывание»** → тип «Веб-приложение»:
   «Выполнять как» — **Я**, «У кого есть доступ» — **Все**. Нажмите «Развернуть» и скопируйте URL
   (заканчивается на `/exec`).
6. Вставьте этот URL в `data.js` в строку `api: '...'` и загрузите `data.js` на GitHub заново.
7. На сайте откройте календарь → «войти для изменений» → введите PIN. На каждом устройстве — один раз.

Если поменяете код сервера: «Развернуть» → «Управление развертываниями» → карандаш →
«Версия: новая» → «Развернуть». Адрес останется прежним.

## Как вставить человечка на другой сайт

```html
<link rel="stylesheet" href="buddy/buddy.css">

<div data-vbuddy style="max-width: 280px"></div>

<script src="buddy/phrases.js"></script>
<script src="buddy/buddy.js"></script>
```

Ширину задаёт `max-width`; высота считается автоматически.
Сверху над головой зарезервировано место под облачко.

## Реакции

| Что происходит | Реакция |
|---|---|
| Курсор двигается | смотрит на курсор, поворачивает голову |
| Курсор стоит 9 секунд | скучает (`bored`) |
| Курсор стоит 26 секунд | засыпает, при движении просыпается (`sleep`, `wake`) |
| Резкое движение мышью | удивляется (`fast`) |
| Курсор у самого лица | «личное пространство» (`close`) |
| Клик по человечку | радуется (`click`); 5 кликов подряд — сердится (`spam`) |
| Курсор ушёл со страницы | грустит (`leave`), возвращение — `back` |
| Быстрый скролл | `scroll` |
| Копирование текста | `copy` |
| Каждые 12–20 секунд | случайная мысль (`idle`) |
| При загрузке | приветствие по времени суток (`hello`) |

## Свои фразы на кнопках

Любому элементу можно задать мысль, которая появится при наведении:

```html
<a href="#projects" data-think="Тут мои проекты" data-mood="smirk">Проекты</a>
```

Эмоции: `neutral`, `smile`, `happy`, `surprised`, `serious`, `sad`, `bored`, `thinking`, `smirk`.

## Управление из кода

```js
const buddy = document.querySelector('[data-vbuddy]').vbuddy;
buddy.say('Гол!', 'happy');   // показать мысль
buddy.mood('smile');          // сменить базовое настроение
```

## Замена графики

Слои лежат в `buddy/assets`. Можно перерисовать любой слой (например, рот или брови)
в Photoshop и сохранить с тем же именем и размером — код подхватит его сам.
